# Simple Interest Calculator

## Description du projet
Ce projet est un calculateur d'intérêts simples développé en Bash. Il permet de calculer l'intérêt simple à partir des entrées de l'utilisateur.

## Comment ça fonctionne ?
Le calculateur demande à l'utilisateur trois valeurs :
1.  **Principal (P)** : Le montant initial emprunté ou investi
2.  **Taux d'intérêt (R)** : Le taux d'intérêt annuel en pourcentage
3.  **Période (T)** : La durée en années
